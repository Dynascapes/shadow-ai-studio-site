# Discord Application Snippets

These are drafts. Do not send without final approval.

## General short intro

```text
Hey, saw your post. I run Shadow AI Studio and help with web builds, cleanup, dashboards, automation workflows, and AI-assisted dev. I can share my site/GitHub if the scope, budget, and timeline are a fit.
```

## Human Reply Rule

Do not reuse the same intake line in every DM. Read the other person's last message first, then reply to that exact situation.

Bad pattern to avoid after they already explained the task:

```text
Send exact task/SRS/budget/timeline.
```

Better pattern:

```text
Got it. If you are handling the client, I can work async through you. We can start with one small milestone so you can judge the output first. I would probably start with auth, booking, or the dashboard skeleton, whichever is most urgent.
```

## General screening question, only before scope is clear

```text
Before I send more details, what part needs help first, what budget range are you working with, and what payment method do you use?
```

```text

```
