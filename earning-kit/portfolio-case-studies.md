## 2. Launch audit and fix workflow

Type: service workflow
Status: internal workflow, public package

Summary:
Created a fixed-scope process for reviewing AI-built sites and small web projects before launch. The workflow checks layout, mobile responsiveness, broken links, forms, deploy errors, payment wording, policy pages, and general trust signals.

What it proves:

- Can turn messy site issues into a prioritized fix list.
- Can communicate technical problems in plain language.
- Can focus on business-critical launch blockers instead of random polishing.

Deliverables:

- Issue list grouped by priority
- Fix notes
- Before/after summary
- Handoff checklist

Good demo repo idea:
Create `launch-audit-checklist` with a sample audit template, markdown checklist, and example report.

## 3. Website lead leak audit sample

Type: sample deliverable
Status: created locally, publish pending
Local page: `lead-leak-audit-sample.html`
Planned live URL after publish: https://dynascapes.github.io/shadow-ai-studio-site/lead-leak-audit-sample.html

Summary:
Created a sample async audit for local businesses that want fewer lost website leads without starting with a call. The sample checks form follow-up, mobile call-to-action placement, missed-call fallback, reviews near the request path, and basic follow-up templates.

What it proves:

- Can package a small service into a written deliverable.
- Can explain business website issues in plain language.
- Can create proof that a client can judge before an interview or call.
- Can keep the first step privacy-safe by not requesting passwords or private customer data.

Deliverables:

- Sample report page
- Priority findings
- 48-hour fix plan
- Follow-up and review request copy
- Async intake requirements

Good usage:
Send this when someone asks for a call before sharing scope, or when we need to prove the service without overexplaining. Use the live URL only after the site is published.

Blunt fit note for advanced jobs:

For industrial AI or specialized backend jobs, pitch the parts we can actually support: frontend dashboards, API/data pipeline support, documentation, deployment cleanup, and AI-assisted implementation. Do not claim PLC, OPC UA, or production industrial experience unless there is real proof.
