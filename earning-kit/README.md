# Shadow AI Studio Earning Kit

Purpose: public-safe materials for Discord job hunting, freelance leads, and small online earning opportunities.

Use these as drafts only. Do not send or publish anything here without a final review.

Files:

- `resume-one-page.md` - one-page contractor resume draft.
- `portfolio-case-studies.md` - honest portfolio blurbs and demo project ideas.
- `github-profile-readme.md` - GitHub profile README copy.
- `discord-application-snippets.md` - short DMs for current leads.
- `website-lead-leak-audit-sample.md` - reusable sample audit deliverable for async-first leads.
- `async-first-offer-kit.md` - short offer, Fiverr, and DM copy for no-call positioning.
- `cold-email-service-playbook.md` - focused plan for selling quote-flow fixes to local service businesses.
- `prospect-tracker-template.csv` - lead tracker columns for targeted manual outreach.
- `kauai-service-first-batch-2026-06-10.md` - first draft outreach batch from the existing Kauai local-business lead list.
- `public-leads-2026-06-10.md` - current public lead notes and platform setup options.
- `message-outbox-2026-06-10.md` - exact drafts/compose links for approved manual or browser-assisted sending.

Safety rules:

- Do not add a home address, SSN, payment info, passwords, cookies, wallet seed phrases, or private account details.
- Do not claim paid client work unless it really happened.
- Label demo/internal work clearly.
- For jobs asking for advanced industrial, financial, medical, or legal systems, frame the offer around the parts we can honestly support.
